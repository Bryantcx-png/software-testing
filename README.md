# SWE3043 Software Testing — CTFL MCQ Practice

Single-file practice app for ISTQB CTFL v4.0, Chapters 1–4. Open on iPhone in Safari → Share → Add to Home Screen.

Paper types:
- **Practice paper / Marathon** – 256 MCQs, marked as you answer.
- **Mock midterm** – Section A: 20 MCQs (5 per chapter), marked on hand-in; Section B: 2 written questions from random topics, self-marked and scaled to 15 each; elapsed time shown.
- **Section B – written questions** – 58 exam-style questions (EP/BVA, decision tables, state transition, white-box, experience-based/ATDD, spec reviews, Chapter 1–3 theory) chosen by topic, self-marked against model answers.
- **Subjective recall (Ch 1–2)** – keyword-marked written answers and memorise tables.

Diagram sources are in `diagrams/`.
